# 📘 数学复习本

一个**完全本地、纯离线**的数学错题与知识点复习网站。无需注册、无后端、
无云端上传，所有数据都保存在你自己的浏览器里。

在线使用：https://fumoran.github.io/math-review-book/

> 手机上可用浏览器「安装应用 / 添加到主屏幕」，安装后即为全屏应用，
> 断网也能正常复习。

## 主要功能

- **错题库 + 知识点库**双库分离，标签共用；解析与知识点默认折叠
- 支持粘贴 AI 按固定格式生成的题目**批量导入**（`【题目】/【解析】/【知识点】/【标签】`，多题用 `===` 分隔）
- KaTeX 公式渲染、**图片上传与压缩**（存 IndexedDB）、导入**去重**提示
- ⭐ 收藏、多标签交集筛选、背题模式、随机一题、返回顶部、长按多选
- **回收站**（软删除 + 30 天自动清理）、JSON 导出导入、Markdown 导出、打印
- 可自定义**分栏 / 主题 / 密度 / 动效**，适配手机、平板横屏与桌面

## 数据与隐私

所有内容仅存于浏览器本地（`localStorage` + `IndexedDB`），不上传任何服务器。
换设备或清理浏览器数据会丢失内容，请**定期使用「导出」备份**。
