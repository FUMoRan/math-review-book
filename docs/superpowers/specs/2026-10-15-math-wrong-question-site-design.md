# 数学错题复习网站 — 设计文档

日期：2026-10-15
状态：待用户确认

## 1. 背景与目标

个人自用的数学错题复习网站。使用者把做错的数学题收集起来，每道题配有**解析**和**相关知识点讲解**，用于考前/日常复习。

核心使用流程：

1. 把题目原文交给 AI（免费版即可），让它按**固定格式**输出题目 / 解析 / 知识点。
2. 复制 AI 的输出，粘进网站的「粘贴导入」入口。
3. 网站按格式自动拆分成字段，使用者确认（可微调）后保存。
4. 复习时看题目卡片，**解析和知识点默认折叠**，先自己想，想完再展开对照。

目标：轻量、离线可用、录入顺手、复习体验好。不做多用户、不做云端。

## 2. 需求清单

必做：

- 自己录入题目、解析、知识点（支持「粘贴 AI 内容」批量导入 + 手动填写/微调）。
- 一次可导入多道题。
- 题目卡片展示，解析与知识点**默认折叠**。
- 数学公式渲染（`$...$` → KaTeX）。
- 按知识点标签筛选、按关键词搜索。
- 每题标记复习状态（未复习 / 复习中 / 已掌握），可筛选。
- 数据存本地，支持导出 / 导入 JSON 备份。

不做（YAGNI）：

- 多用户、登录、云同步。
- 图片/拍照录入（题干为纯文本 + LaTeX）。
- 间隔重复间隔算法（SRS）、艾宾浩斯排程。
- 富文本编辑器。
- 记录「我的错误答案」字段（当前需求未提出，暂不做）。

## 3. 技术选型

- **纯前端单页**：`index.html` + `styles.css` + `app.js`，原生 JS，无框架、无构建步骤。
- **存储**：浏览器 `localStorage`，单个 key 存全部数据。
- **公式渲染**：KaTeX。优先把 KaTeX 发行包放到本地 `vendor/katex/`，保证离线可用；若当前环境无法下载，则改用 CDN 引入（需联网，无法渲染时保留原始 `$...$` 文本，不报错）。
- **部署**：双击 `index.html` 用浏览器打开即可使用。

## 4. 目录结构

```
/workspace/
  index.html          页面骨架
  styles.css          样式
  app.js              全部逻辑（渲染、存储、解析、导入导出）
  vendor/katex/       本地 KaTeX（离线渲染用，可选）
  docs/superpowers/specs/2026-10-15-math-wrong-question-site-design.md
```

`app.js` 内部按职责分块，保持每块单一职责、可独立理解：

- `storage`：localStorage 读写、数据校验。
- `parser`：把粘贴的 `【…】` 文本解析成题目对象数组。
- `render`：列表/卡片/折叠区渲染，KaTeX 渲染公式。
- `ui`：事件绑定、筛选、搜索、模态框、导入导出。

## 5. 导入格式规范（与 AI 的输出约定）

### 5.1 单题格式

标签行必须独占一行，正文在标签行之后：

```
【题目】
（题干。数学公式用 $...$ 包裹，例如 $f(x)=x^2-2x+1$）
【解析】
（分步解析，每步一行，公式同样用 $...$）
【知识点】
（本题涉及的知识点讲解：定义 / 公式 / 易错点）
【标签】
函数单调性, 导数
```

- `【题目】【解析】【知识点】` 为三段正文，可多行。
- `【标签】` 可选，该行内容按「逗号 / 中文逗号」切分为标签数组。
- 各标记必须**独占一行**，作为段落分隔依据。

### 5.2 多题格式

单题之间用一行 `===`（三个及以上等号）分隔，一次可导入多题：

```
【题目】
第一题…
【解析】
…
【知识点】
…
【标签】
导数
===
【题目】
第二题…
【解析】
…
【知识点】
…
【标签】
数列
```

### 5.3 解析规则

1. 按「独占一行的 `=`≥3 个」把整段切成若干 block。
2. 每个 block 内按「独占一行的 `【题目】/【解析】/【知识点】/【标签】`」切段，标记决定字段归属。
3. 允许标记与内容写在同一行（如 `【标签】导数, 函数`），此时标记后的内容即为该字段。
4. 标记之前、不属于任何字段的零散文本：忽略，并在预览里给出提示。
5. 缺少 `【题目】` 的 block 视为无效，预览中标红提示，用户可手动修正或丢弃。
6. 解析只做「拆分」，不改写内容。

### 5.4 配套提示词（使用者每次复制给 AI）

```
你是高中数学老师。请把下面这道题整理成如下固定格式，只输出这个格式，不要任何多余说明
（公式一律用 $...$ 包裹；如需输出多道题，用单独一行 === 分隔）：

【题目】
【解析】
【知识点】
【标签】

要求：
- 【题目】写清完整题干，涉及图形时用文字描述。
- 【解析】分步骤写，突出关键思路与易错点。
- 【知识点】讲清楚本题用到的定义、公式、定理及易错点。
- 【标签】用一行写出本题涉及的知识点关键词，英文逗号分隔。

题目原文：
<把你的题目贴在这里>
```

## 6. 数据结构

`localStorage` key：`mq_items`

```js
// 数组，每项为一道题
{
  "id": "string",          // 唯一 id（时间戳 + 随机后缀）
  "stem": "string",        // 题目（含 $...$）
  "analysis": "string",    // 解析
  "knowledge": "string",   // 知识点讲解
  "tags": ["string"],      // 标签
  "status": "new",         // new 未复习 | reviewing 复习中 | mastered 已掌握
  "createdAt": 0,          // 毫秒时间戳
  "updatedAt": 0
}
```

写数据时全部落盘为一个 JSON 数组；导出即导出该数组，导入即替换或追加该数组。

## 7. 界面与交互

### 7.1 主页面

- 顶部栏：标题、搜索框（搜题干/解析/知识点/标签）、筛选（按标签、按状态）、「新增错题」按钮、「导出 JSON」「导入 JSON」按钮。
- 主区：错题卡片列表。
- 空状态：提示「还没有错题，点新增或粘贴 AI 内容」。

### 7.2 错题卡片

- 显示：题干（KaTeX 渲染）+ 标签 chips + 状态色块。
- **默认折叠**，两个折叠开关：
  - 「查看解析」→ 展开显示解析（KaTeX 渲染）。
  - 「查看知识点」→ 展开显示知识点讲解（KaTeX 渲染）。
- 卡片操作：切换状态（未复习 → 复习中 → 已掌握，循环）、编辑、删除（删除需二次确认）。

### 7.3 新增 / 编辑弹窗

两个入口，共用同一套表单字段：

1. **粘贴 AI 内容**：大文本框 + 「拆分预览」按钮。
   - 拆分后显示 N 道题的预览卡，每张卡可直接编辑字段、可勾选是否导入。
   - 「全部导入」或「导入选中」批量保存。
   - 缺段、无效 block 在预览里高亮提示。
2. **手动填写**：直接填空表单（题目 / 解析 / 知识点 / 标签），单题保存。

编辑已有题目时，用同一表单预填内容。

### 7.4 复习辅助（轻量）

- 筛选「未复习 / 复习中」即可生成待复习清单。
- 「随机一题」按钮：从当前筛选结果里随机抽一道，只显示题干，解析/知识点保持折叠。

## 8. 数据流

```
粘贴文本
  → parser 拆分为题目对象数组
  → 预览（可编辑 / 勾选）
  → 合并进内存数组
  → storage 写入 localStorage
  → render 刷新卡片列表
```

导入 JSON 文件：读取 → 校验结构（必须为数组且每项含 stem 字段）→ 选择「替换」或「追加」→ 写盘。
导出 JSON 文件：内存数组 → `JSON.stringify` → 浏览器下载 `.json`。

## 9. 错误处理

- **粘贴内容缺段 / 无【题目】**：预览高亮提示，不阻止用户手动修正后保存。
- **公式渲染失败**：KaTeX 配置 `throwOnError: false`，渲染失败时保留原始文本，不打断页面。
- **导入 JSON 结构非法**：提示错误，且**不覆盖**现有数据。
- **localStorage 不可用 / 写入失败（如隐私模式、超限）**：捕获异常，顶部提示，并建议先导出备份。

## 10. 测试

在浏览器中手动验证以下路径（必要时用浏览器自动化复核）：

1. 手动新增一道题并保存，卡片出现。
2. 折叠区默认收起；点「查看解析」「查看知识点」正确展开，公式渲染正常。
3. 粘贴单题格式 → 拆分正确 → 导入成功。
4. 粘贴 `===` 分隔的多题 → 拆成多张预览 → 批量导入成功。
5. 缺段文本 → 预览有提示，修正后可保存。
6. 搜索关键词、按标签筛选、按状态筛选，结果正确。
7. 状态循环切换生效并写盘。
8. 导出 JSON → 清空 → 导入 JSON，数据一致（含多题、标签、状态）。
9. 刷新页面后数据仍在。
10. 公式渲染异常输入（如 `$\\bad$`）不导致页面报错。

## 11. 边界与后续可扩展（非本期）

## 12. 知识点库（已追加）

### 12.1 背景

错题里的 `knowledge` 是「为某一题服务的一段讲解」，依附于题目。使用者还需要一个**独立的知识点库**：可脱离题目单独存在、自己新增、单独筛选，用于快速复习概念与公式。

### 12.2 需求

- 顶部提供 `错题` / `知识点` 两个视图切换。
- 知识点独立存储、独立展示，与错题**内容分开**。
- 可自己新增知识点；同时支持按固定格式粘贴 AI 生成的内容。
- 知识点视图复用错题视图已有的能力：搜索、标签筛选、分组、分页、多选批量、状态切换、导出/导入。
- 默认**折叠**：只看名称与标签，点开才看讲解（先回忆、再对照）。

### 12.3 数据结构

`localStorage` key `mq_kps`，数组，每项：

```js
{ id, title, content, tags:[], status, createdAt, updatedAt }
```

- `title` 知识点名称；`content` 讲解正文（含 `$...$`）；`tags` 分类标签；`status` 未掌握/复习中/已掌握。

### 12.4 粘贴导入格式

```
【知识点】
二次函数顶点式
【讲解】
$y=a(x-h)^2+k$，顶点为 $(h,k)$。当 $a>0$ 时开口向上……
【标签】
函数, 二次函数
```

多题之间同样用单独一行 `===` 分隔。

### 12.5 标签与关联

- **标签共用一套**：标签下拉的候选项 = 错题标签与知识点标签的并集，便于统一分类。
- **自动关联**：知识点卡片显示「相关错题 N 道」（按标签求交集），点击后切到错题视图并自动筛选这些标签。两套数据本身仍分开存储，关联只读、不写回。
