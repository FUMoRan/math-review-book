# 试卷「打开后」重构设计

日期：2026-10-18
范围：试卷库的「打开」体验与编辑入口；错题/知识点部分不涉及

## 背景与目标

现状：试卷列表点「打开」→ 弹出一个**小弹窗**（`#paperModal`），里面同时承担「标记对错 + 编辑题目」两件事。题目一多，弹窗又窄又长，必须一直滚。

目标：把「打开后」的呈现与交互重构掉。

- 「打开」= 进入**全屏试卷页**，用于**判分 / 重做**；
- 「编辑题目」拆成**独立入口**（卡片上的「编辑」按钮 → 编辑页）；
- 用「全屏 + 右侧题号导航」解决拥挤与长滚动；
- 额外提供**专注模式（一题一屏）**，作为「一览整卷」之外的另一种视图。

## 入口（试卷卡片）

保留原有「改名」「删除」，并调整为：

- **「打开」**：进入全屏试卷页（默认**判分模式**，答案可见）
- **「编辑」**（新增）：进入编辑页，专门编辑题目内容

## 全屏试卷页（打开后）

### 布局

- 顶部：工具栏
- 中间：题目区（一览整卷时，题目按舒适行宽纵向排布）
- 右侧：**题号导航条**（常驻）
- 窄屏（< 1024px）：题号导航条收为**顶部横条**（或可横向滚动的题号带）

### 顶部工具栏

- 模式切换：`判分` / `重做`（分段控件）
- **专注模式**开关（一览 ↔ 一题一屏）
- 「仅看错题」开关
- 「显示答案 / 隐藏答案」开关（影响重做模式）
- 「加入错题本」（把已标错题入错题本，逻辑沿用现有 `addPaperWrongToBook`）
- 返回（关闭试卷页，回到试卷列表）
- 试卷标题展示（只读；改名仍在卡片上）

### 右侧题号导航条

- 每个题号一个小方块，状态用颜色区分：**对 / 错 / 未标**，当前题高亮
- 点击某方块 → 滚动定位到该题（专注模式下则直接切到该题）
- 顶部显示进度：`已标 x / 共 n`，并显示 `错 m`

### 判分模式（默认）

- 每题显示一个显眼的**三态切换**：`对 / 错 / 未标`
- 键盘快捷键（仅当试卷页打开且焦点不在输入框时生效）：
  - `1` → 标对；`2` → 标错；`0` → 未标
  - `↑ / ↓`（或 `n / p`）→ 上/下一题
- 底部「**跳到下一道未标**」：从当前题往后找第一个未标题并定位；若没有则提示「已无未标」
- 答案可见

### 重做模式

- 默认**遮住答案**：每题有「显示答案」
- 工具栏的「显示答案 / 隐藏答案」作用于整卷
- 状态切换与快捷键同判分模式（做完对照后可直接标对错）

### 专注模式（一题一屏）

- 一次只显示一题：题号、题干（答案默认按当前模式处理）、大按钮「**做对** / **做错**」
- 底部或顶部：「上一题 / 下一题」
- 顶部进度条（当前题 / 总题数）
- 再点专注开关 → 回到一览整卷
- 判分模式与重做模式都可叠加专注模式（专注只是视图，不改变判分/重做的语义）

## 编辑页（独立功能）

- 从试卷卡片「编辑」进入
- 可编辑：标题、日期、逐题题干、逐题答案、题号、删除题目
- 沿用现有单题编辑弹层（`#paperQModal`）作为编辑页内的编辑手段，或内联编辑
- 打开试卷的做题/判分界面**不再提供**任何改题内容的能力

## 移动端

- 题号导航条收为顶部横条
- 专注模式在小屏上体验最佳（一题一屏，底部按钮大）
- 工具栏允许换行/收纳，避免拥挤

## 数据与兼容

- **不改** `papers` 的数据结构（`paper.questions[].{no, stem, answer, wrong, linkedQid}` 不变）
- **不改**导入/导出格式
- 现有状态 `paperWrongOnly`、函数 `renderPaperDetail` 重构为试卷页的渲染与状态（可改名 `renderPaperView`），移除旧的小弹窗 `#paperModal`

## 纯函数与测试

把不依赖 DOM 的决策抽到 [lib.js](../../../lib.js)：

- `nextUnmarked(questions, fromId)`：从 `fromId` 之后向后找，走到末尾后回绕到开头继续找，返回第一个 `wrong === 'unset'` 的题；全部已标则返回 `null`
- 可选：`paperProgress(questions)` → `{ total, right, wrong, unset, marked }`

单元测试（`test/lib.test.js`）覆盖：

- `nextUnmarked`：正常向后找、到末尾、当前题本身未标、全部已标返回 `null`、`fromId` 不存在
- `paperProgress`：各计数正确

浏览器验收四条路径：**判分**（含快捷键、跳下一道未标、题号导航跳转）、**重做**（答案遮蔽与显示）、**专注模式**、**编辑页**。

## 边界处理

- 试卷页打开时，键盘快捷键只在焦点不在 `input / textarea / select` 时生效
- 题目为空（0 题）：显示空态提示
- 「跳到下一道未标」：从当前题之后找，走到末尾后**回绕**到开头继续找；回绕后仍无未标题则提示「已无未标」
- 专注模式下删除/编辑题目：不允许（编辑只在编辑页）
- 关闭试卷页返回列表时，刷新卡片的「错 n」统计
- 「仅看错题」在专注模式下：导航只在错题之间移动

## 非目标（YAGNI）

- 不改试卷的导入（粘贴识别）逻辑
- 不做计时、得分统计、错题本以外的成绩分析
- 不做题目拖拽排序（那是错题/知识点库的独立功能）
