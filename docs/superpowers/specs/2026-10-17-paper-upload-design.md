# 数学复习本 — 「整卷上传 / 试卷栏目」设计文档

日期：2026-10-17
状态：待用户确认
关联：[2026-10-15 复习网站设计](2026-10-15-math-wrong-question-site-design.md)

## 1. 背景与目标

现有复习本是一个「错题本」：单题粘贴导入（`【题目】【解析】【知识点】【标签】`）、KaTeX 渲染、间隔复习（SRS）、标签筛选。

使用者新增诉求：**一次录入一整张卷子的所有题**，并在一个**单独的栏目**里看到整卷题目。录入方式沿用现有老路——把整卷交给免费 AI 识别，复制结果粘进本应用（不接图片 API）。

目标：

1. 新增「试卷」栏目，集中存放整卷，按题号顺序展示整卷所有题。
2. 支持整卷粘贴导入（多题拆分）。
3. 整卷题目默认**不进**错题本；在试卷里逐题标记对/错，标为「错」的可一键加入错题本，进入原有 SRS 复习闭环。

## 2. 非目标（YAGNI）

- 不做 PDF 解析、不做扫描件按题裁剪、不做图片绑定到试卷题目。
- 不做试卷题目的自动 SRS（只有进错题本的题才 SRS）。
- 不做跨试卷统计报表。
- 不做在线 AI 直连整卷（仍走「复制提示词给免费 AI → 粘回」的手动路径）。
- 不新增与「对/错」无关的复杂状态。

## 3. 术语

- **试卷（paper）**：一张卷子，包含有序的若干道题。
- **试卷题目（paper question）**：试卷里的一道题，含题干与答案。
- **错题本条目（question item）**：现有 `mq_items` 里的一条，参与 SRS。
- **三态标记**：试卷题目的 `wrong` 字段，取值 `unset`（未标）/`right`（做对）/`wrong`（错）。

## 4. 数据模型

新增存储 `mq_papers`（IndexedDB，与 `mq_items` / `mq_kps` 并列）。

```
paper = {
  id,                   // uid()
  title,                // 试卷名，默认「未命名试卷」，可改
  date,                 // 考试/录入日期，默认今天
  note,                 // 备注（可选）
  createdAt, updatedAt,
  questions: [ PaperQuestion ]   // 内联，按题号顺序
}

PaperQuestion = {
  id,                   // uid()
  no,                   // 题号，导入时按顺序 1..n，可手动改
  stem,                 // 题干（必填）
  answer,               // 答案（可选，可空）
  wrong,                // 'unset' | 'right' | 'wrong'，默认 'unset'
  tags,                 // string[]，可选
  linkedQid             // 已加入错题本时的错题条目 id；未加入为 null
}
```

错题本条目（现有 `normalizeQuestion`）新增来源字段：

```
fromPaper = { paperId, questionId }   // 可选；由试卷生成的错题才有
```

`normalizeQuestion` 需向后兼容：旧数据无 `fromPaper` 时视为 `null`。

## 5. 栏目与界面结构

- 顶部栏目由 2 个变 3 个：`错题` / `知识点` / `试卷`。
- **试卷列表**：卡片显示 `试卷名 · 题数 · 错题数 · 日期`，点击进入详情。
- **试卷详情**：顺序列出整卷所有题：
  - 每题显示题号 + 题干；「答案」默认折叠，可展开。
  - 每题右侧一个三态开关（未标 / 对 / 错）。
  - 底部操作区：「全部标错」「全部标对」「仅看错题」「把已标错题加入错题本」。
- 试卷详情支持：编辑题目（题干/答案/题号）、删除单题、删除整卷、改试卷名与日期。
- 错题本条目若来自试卷，卡片上显示来源并可回跳到原卷对应题。

## 6. 交互流程

### 6.1 整卷导入

1. 在「试卷」栏目点新增 → 打开粘贴面板（复用现有导入弹窗）。
2. 粘贴整卷文本（免费 AI 输出）。格式：每题 `【题目】` / `【答案】`（或 `【解析】`）/`【标签】`，题与题之间单独一行 `===`。
3. 点「拆分预览」→ 按 `===` 拆分，`parsePaper` 生成试卷对象，预览显示「第 1..n 题 + 答案有无」。
4. 确认后生成 paper，存入 `mq_papers`。

### 6.2 逐题标记

- 试卷题目初始 `wrong = 'unset'`。
- 在详情页用三态开关逐题标记；也可用批量按钮。
- 「仅看错题」切换后只显示标为「错」的题。

### 6.3 加入错题本

- 点「把已标错题加入错题本」：把 `wrong === 'wrong'` 且 `linkedQid == null` 的题逐条生成错题条目：
  - `stem` ← 题目的 `stem`；`analysis` 留空待补；`knowledge` 留空；`tags` ← 题目的 `tags`。
  - 写入 `fromPaper = { paperId, questionId }`，并把生成的条目 id 回写题目 `linkedQid`。
- 已加入过的题显示「已在错题本」且不重复生成。
- **不依赖内置 AI**：解析留空，使用者继续用现有「复制提示词给免费 AI」流程补解析。

## 7. 提示词

新增一份「整卷识别」提示词（供使用者复制给免费 AI），要求：

- 输出整卷所有题，**题与题之间单独一行 `===`**；
- 每题用 `【题目】` / `【答案】` 两个标记；
- 公式一律 LaTeX 且带定界符：行内 `$...$`，跨行（矩阵/方程组/多行推导）用 `$$...$$`；
- 复用并强化现有裸公式反例约束（如 `y'' = \frac{dp}{dx}` 必须写成 `$$y'' = \frac{dp}{dx}$$`）；
- 不使用 Markdown 语法。

## 8. 边界情况

| 场景 | 处理 |
| --- | --- |
| 某题没有【答案】 | `answer` 留空，不影响导入与标记 |
| 整卷拆出 0 题 | 预览提示「没解析到内容，检查格式」，不生成试卷 |
| 重复导入同名试卷 | 提示「已存在同名试卷，是否仍要导入」，确认后允许 |
| 删除试卷 | 已进错题本的条目**保留**（独立存在），仅断开 `fromPaper` 回链 |
| 删除某道题 | 已进错题本的条目同样保留，仅断开回链 |
| 同一题重复加入错题本 | 依据 `linkedQid` 判重，不重复生成 |
| 题号重复/乱序 | 允许手动改题号；展示按 `questions` 数组顺序 |

## 9. 模块划分与数据流

**模块（贴合现有结构）**

- `lib.js`：新增纯函数 `normalizePaper` / `normalizePaperQuestion` / `parsePaper` / `paperWrongToQuestion`；`normalizeQuestion` 增补 `fromPaper` 字段。
- `app.js`：新增 store `p`（key `mq_papers`）、第三个 `DEF` 配置、试卷列表/详情渲染、复用粘贴导入面板、批量标记、加入错题本。
- `index.html`：顶栏加「试卷」按钮 + 试卷列表容器；导入面板文案微调。
- `styles.css`：试卷卡片与详情样式。
- `test/lib.test.js`：新增纯函数单测。

**数据流**

```
粘贴整卷文本
   → parsePaper(text)            => paper 对象
   → 预览确认
   → 存 mq_papers
   → 详情页逐题标记 wrong
   → paperWrongToQuestion(paper) => 错题条目[]（含 fromPaper 回链）
   → 追加进 mq_items（去重，回写 linkedQid）
```

**函数职责**

- `normalizePaperQuestion(o)`：补默认值、`wrong` 合法性（非法回退 `unset`）、`no` 数字化。
- `normalizePaper(o)`：补 `id/title/date/questions`，逐题归一化。
- `parsePaper(text)`：`===` 拆分 → 复用 `parseBlockGeneric`（字段映射：`题目→stem`、`答案|解析→answer`、`标签→tags`）→ 返回 `paper`。
- `paperWrongToQuestion(paper, now)`：挑出 `wrong==='wrong' && !linkedQid` 的题，转成错题条目数组（不改原对象，纯函数）。

## 10. 分阶段

**阶段 1（MVP）**

- 「试卷」栏目 + 整卷粘贴导入 + 详情展示（题干/答案）+ 三态标记 + 一键加入错题本。

**阶段 2（可选）**

- 「整卷识别」提示词按钮；批量「全部标错/标对」；试卷内搜索与筛选；从错题条目回跳原卷。

## 11. 测试计划

沿用现有纯函数单测架构（Node 内置 test runner，无 DOM）：

- `parsePaper`：多题拆分、缺答案、空输入、题号顺序。
- `normalizePaper` / `normalizePaperQuestion`：默认值、非法 `wrong` 回退、`no` 数字化。
- `paperWrongToQuestion`：只挑标错的、跳过已加入的、回链字段正确。
- `normalizeQuestion`：`fromPaper` 缺省与兼容。
- 现有 51 条测试保持全绿。

## 12. 未决 / 后续

- 试卷与错题本之间是否需要「双向同步」（在错题本改了题干，是否回写试卷题）——暂不做，仅单向生成 + 回链。
- 试卷是否需要导出/打印——暂不做。
