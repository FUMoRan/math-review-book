# 合集侧栏「收起 / 展开」设计

日期：2026-10-18
范围：错题/知识点视图的左侧合集栏；试卷视图不涉及

## 背景与目标

现状：宽屏（≥1024px）下合集侧栏是常驻的 238px sticky 栏，无法收起；窄屏（<1024px）下是一条抽屉，用 header 的「☰ 合集」开合。侧栏内已有的「收起」只指**子合集折叠**（`colCollapsed`），与"整个侧栏收起"无关。

目标：让**整个侧栏可以收起 / 展开**，收起后腾出横向空间但仍能快速切换合集。

## 两种形态

- **完整侧栏**：宽约 238px，当前形态（可嵌套树 + 节点操作）
- **窄竖条（rail）**：宽约 44px，收起后的形态

收起状态记录在设置里（全局，错题 / 知识点共用），重开保持。

## 宽屏（≥1024px）

### 完整侧栏 → 收起

- 完整侧栏头部新增「«」收起按钮，点击切到窄竖条

### 窄竖条（rail）

- 位置：屏幕左侧，垂直方向排列
- 内容：竖向排列「全部」「未分类」+ **所有合集（含子合集，平铺，不体现缩进层级）**
- 每项一个方块，显示**名称首字**；当前选中项高亮
- **悬停显示 tooltip**：全名 / 层级路径（如「高数 / 级数」）/ 数量
- **点击方块 = 切换筛选**，等价于在完整树里点击该合集（含"全部""未分类"）
- 顶部「»」按钮：展开回完整侧栏
- 底部保留一个小「＋」，用于新建合集
- 合集较多时竖条可纵向滚动

### header 按钮

- header 的「☰ 合集」在宽屏也显示，一键在「完整侧栏 ⇄ 窄竖条」之间切换

### 与子合集折叠的关系

- `colCollapsed`（子合集折叠）只在完整侧栏里生效
- 竖条是**平铺**展示所有合集，不受 `colCollapsed` 影响

## 窄屏（<1024px）

- 行为**不变**：仍是抽屉，点「☰ 合集」浮出完整树；不做竖条

## 交互与状态细节

- 竖条点击合集：切换 `collectionFilter`，并触发列表重渲染与侧栏高亮更新（复用现有筛选逻辑）
- 竖条与完整侧栏共用同一份选中态；两种形态切换时选中项保持一致
- 收起 / 展开不影响当前筛选与滚动位置

## 数据与兼容

- **不改**合集数据结构（`lib.js` 的合集树与纯函数完全不动）
- 仅新增一个设置项记录"侧栏是否收起"，存放于 `mq_settings`
- 试卷视图下侧栏与「☰ 合集」保持隐藏（现有逻辑）

## 测试

- 该功能主要是 DOM / 交互与响应式，无新增纯函数
- 浏览器验收：
  - 宽屏收起 → 出现竖条、主内容区变宽；展开 → 恢复完整侧栏
  - 竖条点选不同合集 → 列表按该合集（含子树）筛选、高亮正确
  - tooltip 显示全名 / 路径 / 数量
  - 刷新后收起状态保持
  - 窄屏仍是抽屉，不受影响
  - 试卷视图不出现侧栏与「☰ 合集」

## 边界处理

- 合集为空（只有「全部」「未分类」）：竖条照常显示这两项
- 当前选中的合集被删除：选中态回落到「全部」（沿用现有纠正逻辑），竖条相应更新
- 竖条宽度固定，合集名过长时只显示首字 + tooltip，不做省略号截断
- 收起状态下切换到试卷视图：按现有逻辑隐藏侧栏；切回错题/知识点时恢复上次的收起状态

## 非目标（YAGNI）

- 不做竖条拖拽调宽
- 不做窄屏竖条
- 不做竖条内直接改名 / 删除（这些仍在完整侧栏或编辑入口完成）
- 不做"边缘悬停浮出"
